# 30-Day Fusion 360 Challenge

This section documents a focused **30-day daily learning challenge** in Fusion 360, recorded alongside a companion **YouTube playlist**. Each day gets its own folder with the project's CAD files, images, and a full engineering write-up — same documentation standard as the rest of this portfolio, just on a daily cadence instead of a project-by-project one.

## How This Section Works

- One folder per day: `Day-01` through `Day-30`.
- Each folder follows the same layout as every other project in this repo:
  ```
  Day-XX/
  ├── Images/     → front.png, isometric.png, exploded.png
  ├── CAD/        → Fusion360.f3d, Model.step, Model.stl
  ├── Drawings/   → exported drawing PDFs
  └── README.md   → objective, skills, challenges, notes, etc.
  ```
- Each `README.md` has a placeholder line at the top for the matching YouTube video link, so the playlist and repo stay cross-referenced.

## Why This Lives Inside the Main Portfolio (Not a Separate Repo)

This challenge is a continuation of the same learning journey documented in the rest of `Fusion360-CAD-Portfolio`, just compressed into a daily format for the YouTube series. Keeping it in one repo means anyone watching the playlist can also see how each day's skill connects back to the broader roadmap in [`00-Portfolio/Learning-Roadmap.md`](../00-Portfolio/Learning-Roadmap.md).

Once complete, the best 2–3 days from this challenge (e.g. the most advanced or most polished build) can also be cross-linked or promoted into the relevant numbered category folder (e.g. `12-Robotics/`) if they turn into standalone flagship projects.
