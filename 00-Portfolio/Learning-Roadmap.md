# Learning Roadmap

This roadmap tracks the order I'm building skills in and where each stage of the repository fits.

## Phase 1 — CAD Fundamentals ✅ Complete
- [x] Sketching, geometric & dimensional constraints (`02-Sketch-Practice`)
- [x] Extrude, Revolve, basic booleans (`01-Beginner`)
- [x] Fillet, Chamfer, Mirror, Pattern, Shell (`03-Feature-Practice`)
- [x] Multi-component assemblies & joints (`04-Assemblies`)

## Phase 2 — Manufacturing-Aware Design 🟡 In Progress
- [x] Basic 2D engineering drawings (`05-Drawings`)
- [x] Sheet metal fundamentals — flanges, bends, flat patterns (`06-Sheet-Metal`)
- [ ] Formal GD&T tolerancing on drawings
- [x] Intro to CAM — toolpaths & simulation (`10-CAM`)
- [ ] Adaptive clearing & multi-axis CAM strategies

## Phase 3 — Advanced Modeling Techniques 🟡 In Progress
- [x] Surface modeling — loft, patch, stitch (`07-Surface-Modeling`)
- [x] Parametric design — user parameters & equations (`08-Parametric-Design`)
- [ ] Full configuration tables (small/medium/large variants)
- [x] Rendering — materials, lighting, camera (`09-Rendering`)

## Phase 4 — Applied / Personal Projects 🟢 Active
- [x] Reverse-engineered household object redesign (`11-Personal-Redesigns`)
- [ ] A second redesign focused on assembly-level improvement

## Phase 5 — Robotics-Focused CAD 🟢 Active Focus
- [x] 6-DOF robotic arm — joint-driven assembly design (`12-Robotics/01-6DOF-Robotic-Arm`)
- [x] ROS2 delivery robot — chassis & sensor mounts consistent with URDF/TF tree (`12-Robotics/02-ROS2-Delivery-Robot`)
- [ ] Parametric gripper end-effector
- [ ] Full mechanical BOM + wiring/cable-routing pass on the delivery robot
- [ ] Formal URDF/Xacro export pipeline documented end-to-end

## Guiding Principle

Each phase isn't strictly sequential — I revisit earlier phases (e.g., drawings, parametric design) as later robotics projects demand more of those skills. The roadmap reflects **emphasis over time**, not a rigid checklist.
