# Basic Shapes — Extrude & Cut

## Objective
Practice combining multiple sketches and extrude operations (Join, Cut, Intersect) on a single body to understand boolean operations in Fusion 360.

## Skills Practiced
- Sketching on existing faces
- Extrude Join/Cut/Intersect
- Basic hole placement

## CAD Features Used
- Sketch
- Extrude (Join, Cut)

## Challenges
- Extruding a cut in the wrong direction and removing material from the wrong side of the part.
- Sketch plane selection when sketching on a non-origin face.

## How I Solved Them
Used the extrude direction arrows and the 'Flip side to cut' option, and previewed the operation before committing to check the removed volume was correct.

## Engineering Notes
This exercise made the difference between a 'New Body' extrude and a 'Join'/'Cut' extrude click permanently, which is foundational for every assembly-level part later in this repo.
