# Skills Learned

A narrative summary of technical skills developed across this portfolio. For a granular, per-feature proficiency table, see [`Skills-Tracker.md`](../Skills-Tracker.md).

## Core Solid Modeling
Fully constrained sketching, extrude/revolve/sweep/loft, fillets, chamfers, shells, mirrors, and rectangular/circular patterns — the foundation used in nearly every project in this repository.

## Assemblies & Motion
Multi-component assembly design using Fusion 360's Joints workflow (rigid, revolute), joint origin planning, interference detection, and basic motion studies — developed through `04-Assemblies` and matured significantly in the `12-Robotics` projects.

## Engineering Drawings
2D drawing generation from 3D models: base/projected/section views, ordinate and linear dimensioning, and title block completion, aimed at producing machinist-usable documentation rather than just illustrative views.

## Sheet Metal Design
Flange/bend-based modeling, bend allowance/K-factor awareness, flat pattern generation and export, and corner relief handling for laser-cut/bent parts.

## Surface Modeling
Lofting between profiles, patching, and stitching surfaces into watertight solids — applied to organic/ergonomic shapes that solid-only workflows can't easily produce.

## Parametric & Configurable Design
User parameters, equation-driven dimensions, and designing relationships between features (not just naming values) so a single model can represent a family of parts.

## Rendering & Visual Communication
Appearances vs. materials, environment/studio lighting, and camera framing to produce presentation-quality images for documentation and portfolio use.

## CAM / Manufacturing
Toolpath programming (facing, pocketing, contouring, drilling) and simulation-based verification to catch collisions and unrealistic tool engagement before trusting a program.

## Robotics-Specific CAD
The skill this entire portfolio is building toward: designing links and joints with axis placement and mass properties considered from the start, so CAD geometry translates cleanly into a URDF/TF tree for ROS2 simulation (Gazebo/RViz) — demonstrated in the 6-DOF robotic arm and ROS2 delivery robot projects.
