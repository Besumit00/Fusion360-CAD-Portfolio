# Fusion 360 Shortcuts Cheat Sheet

## Sketch
| Action | Shortcut |
|---|---|
| Create Sketch | S |
| Line | L |
| Rectangle | R |
| Circle | C |
| Sketch Dimension | D |
| Trim | T |
| Extend | X |
| Finish Sketch | Esc / Stop Sketch button |

## Solid Modeling
| Action | Shortcut |
|---|---|
| Extrude | E |
| Revolve | R (in Create menu context) |
| Fillet | F |
| Shell | Shift+S |
| Combine | Ctrl+B |
| Move/Copy | M |

## Navigation
| Action | Shortcut |
|---|---|
| Orbit | Shift + Middle Mouse |
| Pan | Middle Mouse Drag |
| Zoom | Scroll Wheel |
| Fit to View | Shift+Home |
| Look At (align view to face) | L |

## General
| Action | Shortcut |
|---|---|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Save | Ctrl+S |
| Measure | I |
| Parameters Dialog | Modify → Change Parameters |
