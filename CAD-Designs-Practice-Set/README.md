# CAD Designs Practice Set

This section documents mechanical modeling practice using free dimensioned drawing sheets published by **CAD Designs** ([www.caddesigns.in](https://www.caddesigns.in)) — a resource offering practice drawings originally intended for AutoCAD, CATIA, NX, SolidWorks, and Pro/E, modeled here instead in Autodesk Fusion 360.

## Source & Attribution

These practice drawings — full four-view dimensioned sheets (front, right/side, section views, and isometric) — are created and distributed by CAD Designs (caddesigns.in) as free practice resources. The drawings and dimensions are the original source's work; what's mine is the 3D modeling — interpreting each orthographic/section view and building the part in Fusion 360.

This is kept as a separate practice set from the [`Machine-Design-Practice-Pack/`](../Machine-Design-Practice-Pack/README.md), which is a different 25-part set credited to Curtis Waguespack / KKMSoft — keeping the two separate avoids mixing up attribution between sources.

**Note on reference material:** the original reference drawing sheet for each part is kept in that part's `Ref/` subfolder and is included in this public repo alongside my own models and renders, for anyone following along who wants to see the source drawing being modeled.

## How This Section Works

- One folder per part, numbered in the order I work through them (not tied to any official numbering from the source).
- Each folder follows the same layout as every other project in this repo:
  ```
  NN-Part-Name/
  ├── Images/     → Isometric.png, etc.
  ├── CAD/        → Model.step, Model.obj, Model.mtl
  ├── Ref/        → original reference drawing sheet (included in repo)
  └── README.md   → objective, skills, challenges, notes, etc.
  ```
