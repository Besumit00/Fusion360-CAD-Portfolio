# First Solid Box

## Objective
Learn the absolute fundamentals of Fusion 360 — creating a sketch on a plane, constraining it fully, and extruding it into a solid body. This was my very first modeled part and the starting point of this entire portfolio.

## Skills Practiced
- Basic sketching (rectangle, dimensions)
- Fully defined sketches
- Extrude (New Body)
- Basic navigation, view cube, orbit/pan/zoom
- Understanding the Fusion 360 timeline

## CAD Features Used
- Sketch
- Extrude

## Challenges
- Getting sketches to show as fully constrained (green) instead of under-defined (blue).
- Understanding the difference between sketch planes and construction planes.

## How I Solved Them
Used the 'Show/Hide sketch dimensions' toggle and added missing dimensional and geometric constraints one at a time until the sketch turned green.

## Engineering Notes
This part has no functional purpose — it exists purely to build muscle memory for the sketch → constrain → extrude workflow that underlies almost every later model in this portfolio.
