# Learning Resources

A running list of resources I've used or plan to use while building this portfolio.

## Fusion 360
- Autodesk's official Fusion 360 learning & documentation portal
- Autodesk Fusion 360 YouTube channel (official tutorials)
- Fusion 360 community forums for troubleshooting specific modeling errors

## Robotics / ROS2 / URDF
- ROS2 official documentation
- URDF/Xacro tutorials for describing robot links and joints
- Gazebo simulation documentation

## Design & Manufacturing References
- ASME Y14.5 (GD&T standard) reference material
- Standard fastener/thread size tables (ISO metric)
- 3D printing design-for-manufacture (DFM) guidelines (wall thickness, overhangs, tolerances)

## Notes-to-Self
- Keep a running note in each project's README of *why* a design decision was made, not just what was done — this is what separates a portfolio from a tutorial archive.
- Revisit `Skills-Tracker.md` roughly every month and be honest about proficiency changes.
