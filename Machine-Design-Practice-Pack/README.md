# Machine Design Practice Pack

This section documents my work through a well-known 25-part machine design CAD practice set, modeled in Fusion 360 rather than the original Autodesk Inventor these exercises were written for.

## Source & Attribution

This exercise set — 25 detailed part drawings ranging from simple fixture blocks to threaded inserts, coil-based drill bits, and sectioned housings — was created by **Curtis Waguespack** and distributed by **KKMSoft** as a free Autodesk Inventor practice resource. These are not my own designed parts; the drawings and dimensions are the original author's work. What's mine is the actual 3D modeling: interpreting each drawing, choosing a feature-based modeling strategy, and building the part in Fusion 360.

I'm including this here because working through a structured, professionally-designed practice set is a meaningful complement to my self-directed daily challenge — it exposes me to modeling techniques and part types (coils, sectioned housings, sheet metal notching, shared-sketch assemblies) that I might not think to practice on my own.

## How This Section Works

- One folder per part, numbered in the order given in the original practice set.
- Each folder follows the same layout as every other project in this repo:
  ```
  NN-Part-Name/
  ├── Images/     → front.png, isometric.png, etc.
  ├── CAD/        → Fusion360.f3d, Model.step, Model.stl
  ├── Drawings/   → exported drawing PDFs (optional)
  └── README.md   → objective, skills, challenges, notes, etc.
  ```
- Folders are added as I complete each part — not all 25 are scaffolded upfront.
